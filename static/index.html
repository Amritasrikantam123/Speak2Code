What is MiniLang?

MiniLang is a natural language compiler that translates plain-English statements into C++ code. Write programs as you'd explain them to a person — MiniLang handles the rest.

Variable Declaration

  • Use create, declare, let, or make
  • Example: create variable x with value 5
  • Example: let y be 10

Assignment & Arithmetic

  • Use set, assign, update, or evaluate
  • Example: set result to x plus y
  • Example: assign z to a times b

Print / Output

  • Use print, show, display, or output
  • Example: print result
  • Example: show the value of x

If Statements

  • Start with if, end with end if
  • Comparisons: greater than, less than, equal to, not equal
  • Example: if x greater than 5 … end if

While Loops

  • Start with while, end with end while
  • Example: while i less than 10 … end while
